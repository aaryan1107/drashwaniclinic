# Components

This React/Vite app keeps most UI in `src/main.jsx` with vanilla CSS in `src/styles.css`. Shared UI patterns are function components inside `src/main.jsx`: `ProfileButton`, `PatientNav`, `MetricTile`, `LiveAvailabilityViewer`, `UrgentCareBanner`, `PatientStoriesCarousel`, `PatientChat`, `HealthUpdates`, `BookAppointment`, doctor dashboard sections, and education editor cards.
